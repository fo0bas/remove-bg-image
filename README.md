**Мне надоело то что бы удалить фон с изображения нужно пользоваться платными сервисами поэтому за часик написал Rembg Studio**


**Rembg Studio** – лёгкое десктоп‑приложение на Python + PyQt5, которое ускоряет обработку изображений, удаляя фон с помощью моделей `rembg` (U²‑Net, SAM, BiRefNet и др.).

## Что это?
Локальное GUI‑приложение для единичного или массового удаления фона с изображений.  
Использует библиотеку **rembg** и несколько популярных сегментационных моделей
(U‑Net, SAM, BiRefNet, …). При первом запуске модели скачиваются автоматически.

## Требования
- Python 3.9 – 3.12  
- pip, virtualenv (рекомендовано)  

Установка
```bash
# 1️⃣ Клонировать репозиторий
git clone https://github.com/yourname/rembg-studio.git
cd rembg-studio

# 2️⃣ Создать и активировать виртуальное окружение
python -m venv .venv
# Linux/macOS
source .venv/bin/activate
# Windows
.\.venv\Scripts\activate

# 3️⃣ Установить зависимости
pip install -r requirements.txt
```

`requirements.txt` содержит минимум:

```
PyQt5
rembg
Pillow
```

## Запуск
```bash
python rembg_studio.py
```

После старта можно:
- Перетащить файлы/папки в окно или добавить их через кнопку **«+ Добавить изображения»**.  
- Выбрать модель в выпадающем списке (по‑умолчанию `U²‑Net`).  
- Указать папку для сохранения результатов и режим перезаписи.  
- Нажать **«Удалить фон»** – обработка происходит в отдельном потоке, UI не блокируется.  
- Кнопка **«Телеграмм»** в правом углу открывает `https://t.me/f0bass` (синий цвет).
